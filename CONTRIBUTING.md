# Contributing to Chaufa

Thank you for your interest in contributing to Chaufa.

## How to Contribute

1. Fork this repository.
2. Create a new branch for your feature or fix: `git checkout -b feature-name`
3. Ensure your proposed changes strictly adhere to Chaufa's core design principles:
   - Text output lines start with `/`.
   - Command and execution lines start with `:`.
   - Keep the system lightweight, data-focused, and free of non-essential dependencies (no GUI or audio features).
4. Submit a Pull Request with a clear description of your changes.

## Reporting Issues

If you encounter a bug or inconsistency in the `chaufa.py` interpreter or documentation, please open an issue describing the problem and steps to reproduce it.
