# Changelog

All notable changes to the Chaufa project will be documented in this file.

## [1.0.0] - 2026-10-13

### Added
- Initial release of the `chaufa.py` reference interpreter.
- Execution support for `.cha` source files.
- Text output syntax using `/`.
- Command execution syntax using `:`.
- Support for variable storage, value loading (`:loadvar`), and log history management (`:log`, `:showlog`).
- Comprehensive core documentation (`README.md`, `functions.md`, `examples.md`, `LICENSE`, `INSTALL.md`).
