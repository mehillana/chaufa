# Security Policy

## Supported Versions

Only the latest main version of Chaufa receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |

## Reporting a Vulnerability

If you discover a security vulnerability within the Chaufa interpreter:

- Do not open a public issue.
- Contact the project maintainer directly through GitHub profile channels.
- Your report will be acknowledged and evaluated promptly.
